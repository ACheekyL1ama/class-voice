# 📮 班级民心意见箱 · 真匿名心声投递站 (GitHub Pages 专用版)

专为班级民主建设与班会集中回应打造的现代高颜值意见收集网站。采用 **「100% 真匿名 + 随机回执码跟进 + 自愿留联系方式 + 班会全屏投屏回应」** 模式。

---

## ✨ 核心亮点与功能

1. **🔒 100% 真匿名保护（含透明数据包自检）**
   - 无需注册登录，不采集 IP 地址或设备指纹。
   - 内置「🛡️ 匿名检测」弹窗，向全班同学公开展示实际提交的 JSON 字段，打消“假匿名”顾虑，让同学敢说真话。
2. **🎫 专属【回执码】机制（专为班会集中答复设计）**
   - 每次投递自动生成类似 `#MX-8A3F` 的唯一回执码。
   - **班会上怎么用？** 班委无需打听是谁写的，直接在班会上播报：*“下面回应回执码 `#MX-8A3F` 同学提出的关于考前互助答疑的建议……”*，发信同学一听就知道自己的意见被重视了，同时全程保护面子与隐私！
   - 同学还可凭回执码在网页上随时查询是否已列入班会议程，或匿名追加补充说明。
3. **🙋 自愿留下联系方式 & 公开/私密双通道**
   - 同学可自由选择「📢 允许在民心墙与班会大屏展示」或「🔒 仅班委内部查阅（私密反映）」。
   - 提供折叠的「自愿留下联系方式（选填）」栏，仅在需要班委一对一私下联系时填写，且在公开民心墙和班会投屏时**自动严格隐藏**。
4. **👍 班会公开民心墙 & 同感附议 (+1)**
   - 公开意见展示在民心墙上，全班同学可以点击「👍 我也有同感 (+1)」，帮助班委快速识别全班最关心的痛点议题。
5. **🎬 班委工作台 & 教室大屏投屏模式 (Spotlight Projector)**
   - 班委输入管理口令（默认 `8888`）即可进入后台。
   - 支持**一键开启全屏班会投屏模式**（支持键盘 `⬅️` `➡️` 翻页、现场一键标记「✅ 班会已回应」），直接在教室投影仪/智慧黑板上展示议题。
   - 支持一键导出 **班会汇报稿 (`.md`)** 和 **Excel 统计台账 (`.csv`)**。

## 🚀 3 分钟部署到 GitHub Pages 教程

### 第一步：配置免费云端存储（实现全班跨手机实时汇总）

由于 GitHub Pages 是纯静态托管，为了让全班同学在各自手机上提交的意见能汇总到一起，网站内置了 **JSONBin.io 零代码一键云存储** 支持（完全免费，无需写后端或建表）：

1. 用浏览器打开本项目的 [`index.html`](file:///d:/投票网站/index.html)，点击顶部导航栏的 **「💻 本地演示模式（点此配置云端）」**。
2. 在弹窗中修改你的**班级名称**、**近期班会时间地点**和**班委后台口令**。
3. 将存储模式切换为 **「☁️ JSONBin.io 免费云存储」**：
   - 访问 [jsonbin.io](https://jsonbin.io) 免费注册账号（支持 GitHub 一键登录）。
   - 点击左侧菜单 **API Keys**，复制你的 `X-Master-Key` 粘贴到网页配置框中。
   - 点击网页上的 **「✨ 一键自动创建」** 按钮，系统会自动帮你建好云端意见箱并填入 `Bin ID`！
4. 点击弹窗底部的 **「📋 复制 config.js 代码」**，将复制好的代码粘贴覆盖到项目的 [`js/config.js`](file:///d:/投票网站/js/config.js) 文件中保存。

> 💡 **可选邮件提醒**：如果你希望同学一提交意见，你的邮箱就立刻收到通知，可以去 [web3forms.com](https://web3forms.com) 输入你的 QQ/163 邮箱免费获取一个 `Access Key` 填进配置里即可！

### 第二步：上传到 GitHub 并开启 GitHub Pages

1. 在 GitHub 上新建一个公开仓库（例如命名为 `class-voice`）。
2. 将当前文件夹下的所有文件上传到该仓库：
   - `index.html`
   - `css/style.css`
   - `js/config.js`
   - `js/storage.js`
   - `js/app.js`
3. 进入 GitHub 仓库的 **Settings（设置） -> Pages**。
4. 在 **Build and deployment -> Branch** 下选择 `main`（或 `master`）分支，点击 **Save**。
5. 等待约 1 分钟，页面顶部就会显示你的专属网站链接（如 `https://你的用户名.github.io/class-voice/`），直接把链接或生成的二维码发到班级群即可使用！
